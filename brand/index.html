A paragraph of body text. We think of a perspective as the opinionated middle of a category — not the average, not the trend. When an expert spends fifteen years refining their judgment, what they have is not more information. It’s a way of seeing. That’s what installs here.

A pull quote. “The real differentiator is that I take textual documents and I extract perspective from them, and then I make that perspective citable in the individual task.”

An unordered list of qualities:

  • Citable — every claim traces to a memory and a human source.
  • Versioned — in git, diffable, reviewable.
  • Portable — across every MCP-compatible tool.

An ordered list:

  1. Interview an expert.
  2. Extract perspective, not information.
  3. Install into the AI that does the work.

Inline elements: aswritten_cite(...) returns supported claims with footnotes, emphasis for soft stress, and strong for hard stress. A link to the product manual uses the blue accent — only on docs, not the landing page.

The canonical wordmark is all-lowercase with .ai set as a bracketed superscript. Never AsWritten, AS Written, or Aswritten. In running prose, plain lowercase aswritten (no bracketed superscript) is fine; the superscript is a display mark, not a text treatment.

Spacing scale

Not yet in v0 tokens. Current surfaces use ad-hoc rem values. A 4/8 or 8/16 scale is a candidate for Daniel’s v1. When it lands, add it to tokens.json under "spacing": {...} and visualize here.

Usage rules

  • Write aswritten lowercase. In headlines, body copy, code comments. Domain is aswritten.ai — lowercase. The wordmark with the bracketed superscript is for display only (hero, nav, footer, hero video title).
  • , aswritten is a mode marker. Lowercase, preceded by a comma, used as a suffix in prompts to signal “use real sources, cite, don’t fabricate.” Preserve the comma and the lowercase. Don’t explain it — context teaches the reader.
  • Gold is reserved for expertise-adjacent chrome. Citation rails, credentialing surfaces, “installable” callouts. Not decorative.
  • Blue is for docs links only. Not on landing, not in marketing. Keeps the landing’s palette unconflicted with the docs’ read.
  • Mint pairs with the dark theme. On the light surfaces it reads as confetti — use sparingly.
  • Terracotta vs. red. Until Daniel’s v1 picks one, treat them as synonyms: pick whichever the surface already uses and don’t introduce the other.
