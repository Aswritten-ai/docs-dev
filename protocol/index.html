The aswritten protocol

aswritten gives your AI your organization’s perspective: what was decided, by whom, and why, cited to the conversation it came from. The aswritten server gives your AI the tools. The protocol gives it a way of working with them.

Without the protocol the agent can still read and write. With it, the agent is guided to recognize what a decision looks like, to write memories worth keeping, to understand the implications of a change, and to use those changes to produce cited documents and to project the organization’s shifting narratives and beliefs forward — so you can see not only where your organization stands but where it is heading.

If your AI told you the protocol is not installed, this page is the fix. It is two files, generated from the same sources the product installs from, so they are always the current version.

Claude Code, Codex, Gemini CLI

The short way: open the folder you work in and type the name of your perspective’s repository and the word aswritten — owner/repo aswritten. Your AI connects the folder to that perspective and, when you say yes, installs the protocol into the folder’s CLAUDE.md. In a folder that is its own repository, aswritten alone is enough. Branches are main unless you name one.

CLAUDE.md — the same block, to save by hand into the folder you open Claude Code in. If the folder already has a CLAUDE.md, add this file’s contents to it.

Claude Desktop, claude.ai Projects, ChatGPT

project-instructions.txt — open it, select all, and paste into your project’s custom instructions. It is the core protocol followed by the full reference, in one piece, because these clients cannot read MCP resources. Start your chats in that project.

The server

Claude Code, Codex and Gemini CLI connect with one command, once:

claude mcp add --scope user --transport http aswritten https://api.aswritten.ai/mcp

Then /mcp to sign in. Claude Desktop and claude.ai connect through a custom connector at the same address.

The version

Each file carries a Protocol version: line. Your AI passes that token to aswritten_perspective; the server confirms the protocol is current and stays silent, or tells you what changed and how to update. What changed between versions: the changelog.
